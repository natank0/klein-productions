# קליין הפקות – אתר

אתר סטטי (HTML, CSS ו-JavaScript מצומצם, בלי שרת ובלי שירותי צד שלישי) לעסק ההגברה "קליין הפקות".

- אתר חי: https://natank0.github.io/klein-productions/
- פרסום: GitHub Pages מהענף `main` (תיקיית השורש).

## מבנה
- `index.html` – דף האתר בבני ברק
- `sitemap.xml` – מפת אתר לחיפוש (לשליחה ב-Search Console)
- `404.html` – עמוד לכתובות שלא קיימות (למשל עמוד בית שמש הישן), עם קישור לדף הראשי, חיוג ווואטסאפ
- `assets/css/site.css` – עיצוב משותף (נייר חם, פחם, זהב מט; גופני מערכת)
- `assets/js/site.js` – תפריט מובייל וטופס הצעת מחיר שפותח הודעת וואטסאפ מוכנה
- `tests/run.js`, `package.json`, `.htmlvalidate.json` – בדיקות אוטומטיות (לא חלק מהאתר)
- `.github/workflows/qa.yml` – הרצת הבדיקות בכל PR
- `assets/img/` – לוגו מכווץ (`logo-88/132` ב-WebP ו-JPG), אייקונים ותמונת שיתוף. `logo-full.jpg` הוא קובץ המקור.

## המחשת המחסן (פרק "בלב בני ברק")

- המודול מציג נקודת מיקום אחת בלבד: מחסן קליין הפקות, כהנמן 64, בני ברק.
- `assets/img/city-schematic.jpg` היא המחשה עירונית מקורית וסכמטית. היא אינה מפת רחובות, אינה טוענת לדיוק גאוגרפי ואינה מציגה מסלולים או זמני הגעה.
- הכתובת מוצגת כטקסט רגיל ונגיש גם ללא JavaScript. התמונה דקורטיבית ומסומנת בהתאם.
- כפתורי Waze ו-Google Maps משתמשים באייקוני המוצר המקומיים שנשמרו מדומייני השירותים הרשמיים; הטקסט הגלוי נשאר מקור המשמעות. סימני המסחר שייכים לבעליהם, ואין בכך טענה לשותפות או לחסות.
- קישורי הניווט מבצעים חיפוש לפי הכתובת המאושרת, ללא קואורדינטות מומצאות.
- אין במודול שמות יעדים אחרים, גלריות או נתוני לקוחות.

## בדיקות (`npm test`)
- **התקנה והרצה:** `npm ci`, `npx playwright install chromium`, ואז `npm test`. התלויות משמשות לבדיקות בלבד ולא נטענות באתר.
- **מתי הן רצות:** בכל PR ובכל דחיפה ל-`main` (`.github/workflows/qa.yml`). מיזוג רק כשהבדיקות ירוקות.
- **מה נבדק** (`tests/run.js`; כל כלל של הפרויקט הוא בדיקה):
  - **HTML:** תקינות לפי html-validate (`.htmlvalidate.json`).
  - **כללי תוכן:** אין כתובות אולמות, אין טענות שלא אושרו ("המובילים", "סניף", ותק, מחירים), מספר טלפון אחד, ואין משאבים חיצוניים.
  - **אבטחה:** CSP בלי `unsafe-inline`, hash תואם לכל סקריפט מוטבע, אין `style` מוטבע, וקישורים לחלון חדש עם `noopener`.
  - **פריסה בעשרה רוחבים (320 עד 1920):** אין גלילה אופקית, אזורי מגע של 44px לפחות, אין שגיאות, אין הפרות CSP ואין בקשות חיצוניות.
  - **נגישות:** axe בלי הפרות אוטומטיות (WCAG 2.2 AA), לצד בדיקות מקלדת ומצב ללא JavaScript.
  - **טופס:** תגי אירוע, שמירת בחירה, "טרם נקבע", 7 מקרי טלפון, תאריך שעבר, יום שבת, 400 תווים והעתקה. וואטסאפ מיורט, ושום הודעה לא נשלחת.
  - **מיקום:** פין מחסן יחיד, כתובת, קישורי ניווט ואייקונים מקומיים.
  - **תנועה, בלי JS, ו-404.**
- **בדיקות רגרסיה:** הכללים מכסים טלפון שגוי, כתובת לא מאושרת, `style` מוטבע, משאב חיצוני, רכיבי מיקום ישנים ונוסח שיווקי אסור.

מקורות אייקוני המוצר: `https://www.waze.com/favicon.ico` ו-`https://www.google.com/images/branding/product/ico/maps15_bnuw3a_32dp.ico` (נשמרו מקומית כדי לא ליצור בקשות רשת בזמן השימוש באתר).

## אבטחה ופרטיות
- **CSP קשיח** בתגית meta:
  - `default-src 'none'`, וסקריפטים וסגנונות רק מהאתר.
  - סקריפט מוטבע אחד מאושר ב-hash. אם משנים אותו, מעדכנים את ה-hash, והבדיקות מזכירות.
  - `connect-src 'self'` מאפשר בקשות רק לאתר עצמו, למשל כשבודקי SEO קוראים את `robots.txt`.
- **גרסאות לקבצים (`?v=`):** GitHub Pages שומר CSS ו-JS במטמון הדפדפן 10 דקות. אחרי כל שינוי ב-`site.css` או ב-`site.js` מריצים `npm run stamp`. הוא מעדכן את `?v=` לפי תוכן הקובץ, כך ש-HTML חדש לא נטען עם CSS ישן. הבדיקות נכשלות אם שוכחים.
- **בדיקה מול האתר החי:** `QA_BASE=https://natank0.github.io/klein-productions/ npm test`.
- **אין שירותי צד שלישי:** בלי גופנים, CDN, אנליטיקה או עוגיות. הטופס לא שולח נתונים לשום שרת, רק מכין הודעת וואטסאפ במכשיר של הפונה.
- **מגבלה ידועה:** GitHub Pages לא מאפשר כותרות HTTP, ולכן אין `frame-ancestors` ואין HSTS מותאם. בדומיין פרטי מאחורי CDN אפשר להוסיף אותן.

## פס החיוג במובייל
מוסתר כל עוד כפתורי מסך הפתיחה גלויים, וכשהמקלדת פתוחה בזמן הקלדה. בלי JavaScript הוא מוצג תמיד. הריווח שלו נמצא בתוך הפוטר, כך שהרקע הכהה מגיע עד תחתית המסך.

## הוספת תמונות בהמשך
העמודים שלמים גם בלי תמונות. כדי להוסיף תמונה לכניסה של סוג אירוע, מוסיפים בתוך `<article class="entry">`:

```html
<figure class="entry-media">
  <img src="assets/img/events/wedding-1200.webp" alt="תיאור התמונה" width="1200" height="525" loading="lazy" decoding="async">
</figure>
```

כדאי להעלות תמונות דחוסות (WebP, עד כ-150KB), בלי תמונות של נשים ובלי קהל מעורב.
