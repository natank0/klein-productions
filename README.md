# קליין הפקות – אתר

אתר סטטי (HTML, CSS ו-JavaScript מצומצם, בלי שרת ובלי שירותי צד שלישי) לעסק ההגברה "קליין הפקות".

- אתר חי: https://natank0.github.io/klein-productions/
- פרסום: GitHub Pages מהענף `main` (תיקיית השורש).

## מבנה
- `index.html` – דף האתר בבני ברק
- `sitemap.xml` – מפת אתר לחיפוש (לשליחה ב-Search Console)
- `404.html` – עמוד לכתובות שלא קיימות (למשל עמוד בית שמש הישן), עם קישור לדף הראשי, חיוג ווואטסאפ
- `assets/css/site.css` – עיצוב משותף (נייר חם, פחם, זהב מט; גופני מערכת)
- `assets/js/site.js` – תפריט מובייל וטופס הצעת מחיר שפותח הודעת וואטסאפ מוכנה
- `assets/img/` – לוגו מכווץ (`logo-88/132` ב-WebP ו-JPG), אייקונים ותמונת שיתוף. `logo-full.jpg` הוא קובץ המקור.

## רדאר אולמות השמחה (פרק "בלב בני ברק")
- **מה הרדאר מציג:** המחסן בכהנמן 64 במרכז. כל אולם ממוקם לפי **הכיוון והמרחק היחסי בקו אוויר** מהמחסן.
  - **מקור הנתונים:** OpenStreetMap למחסן, לוגשל, לגני הדקל, להיכלי מלכות, לרויאל, לארמונות חן ולדונולו. למרום, להדודאים ולהיכלי הפאר, שאינם ב-OpenStreetMap: Waze ואתרי אולמות.
  - **מרחק:** הרדיוס הוא `44% × √(מרחק/2000 מ׳)`.
  - **התרשים סכמטי:** אין מרחקים מוצגים ואין כתובות של אולמות.
- **אשכול:** גני הדקל, היכלי מלכות, רויאל, היכלי הפאר וארמונות חן רחוקים זה מזה כמה עשרות מטרים בלבד, ולכן מוצגים כנקודה אחת (במרכז הממוצע שלהם).
- **מקרא גלוי:** מתחת לרדאר יש רשימה מהקרוב לרחוק. הוא משמש גם בלי JavaScript וגם לקוראי מסך.
- **תנועה:** פעימה אחת מהמחסן כשהרדאר נכנס למסך. בהפחתת תנועה אין תנועה בכלל.
- **הוספת אולם:** מחשבים מיקום (`left/top` ו-`--d`) לפי הנוסחה שלמעלה, ומוסיפים את האולם בשלושה מקומות: `li.radar-node`, `li` במקרא, ומפתח ב-`#hallMedia`.

### מדיה לכל אולם
- **איפה:** בסוף `index.html` יש `<script type="application/json" id="hallMedia">`, עם מפתח לכל אולם: `vagshal`, `dekel`, `malchut`, `royal`, `hapeer`, `chen`, `donolo`, `marom`, `dudaim`.
- **מה קורה כשמוסיפים פריטים:** שם האולם במקרא הופך לכפתור, וגם השם ברדאר נהיה לחיץ. הלחיצה פותחת חלון עם הגלריה.
- **דוגמה:**

```json
"chen": [
  { "type": "image", "src": "assets/media/halls/chen/chuppah-1200.webp", "srcset": "assets/media/halls/chen/chuppah-800.webp 800w, assets/media/halls/chen/chuppah-1200.webp 1200w", "sizes": "(max-width: 900px) 100vw, 840px", "width": 1200, "height": 800, "alt": "עמדת הגברה בחופה", "caption": "הגברה לחופה ולעזרת נשים" },
  { "type": "video", "src": "assets/media/halls/chen/event.mp4", "mime": "video/mp4", "poster": "assets/media/halls/chen/event-poster.webp", "captions": "assets/media/halls/chen/event.he.vtt", "width": 1280, "height": 720 }
]
```

- **כללים:**
  - מעלים רק מדיה מאושרת לפרסום.
  - בלי נשים ובלי קהל מעורב.
  - תמונות WebP עד כ-150KB.
  - סרטון עם פוסטר. הוא לא מתחיל לנגן מעצמו ולא נטען מראש.

טלפון `052-7675138` (`tel:0527675138`), וואטסאפ `972527675138`. הם מופיעים בכל עמוד, וב-`WA_NUMBER` שבתוך `site.js`.

## פס החיוג במובייל
מוסתר כל עוד כפתורי מסך הפתיחה גלויים, וכשהמקלדת פתוחה בזמן הקלדה. בלי JavaScript הוא מוצג תמיד. הריווח שלו נמצא בתוך הפוטר, כך שהרקע הכהה מגיע עד תחתית המסך.

## הוספת תמונות בהמשך
העמודים שלמים גם בלי תמונות. כדי להוסיף תמונה לכניסה של סוג אירוע, מוסיפים בתוך `<article class="entry">`:

```html
<figure class="entry-media">
  <img src="assets/img/events/wedding-1200.webp" alt="תיאור התמונה" width="1200" height="525" loading="lazy" decoding="async">
</figure>
```

כדאי להעלות תמונות דחוסות (WebP, עד כ-150KB), בלי תמונות של נשים ובלי קהל מעורב.
