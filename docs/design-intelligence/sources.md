# אינדקס מקורות מקצועיים

הסריקה בוצעה ב-17.11.2026 על הקבצים הזמינים בפועל בתיקיית המחקר הפרטית. ספרי המקור אינם חלק מהמאגר.

| מקור | פורמט ונגישות | שימוש ממוקד בפרויקט |
|---|---|---|
| Steve Krug, *Don't Make Me Think, Revisited* (2013) | PDF, 214 עמ'; טקסט נגיש, לא מתויג | ניווט, בהירות מיידית, קיצור מסלולי פנייה ובדיקות שימושיות |
| Adam Wathan & Steve Schoger, *Refactoring UI* | PDF, 218 עמ'; טקסט ואיורים | היררכיה, מרווחים, צבע, רכיבים וצפיפות |
| Ellen Lupton, *Thinking with Type* | PDF, 259 עמ'; טקסט ואיורים | קצב קריאה, היררכיה טיפוגרפית ויחסי טקסט-גריד |
| Torrey Podmajersky, *Strategic Writing for UX* | PDF, 593 עמ'; טקסט נגיש | מיקרוקופי, שמות פעולות, שגיאות ואמון |
| Heydon Pickering, *Inclusive Components* | EPUB; טקסט, קוד ואיורים נגישים לפי פרקים | רכיבי disclosure, תפריטים, טפסים וגישת progressive enhancement |
| Andy Clarke, *Art Direction for the Web* | PDF, 345 עמ'; טקסט ואיורים | קומפוזיציה מובחנת, טיפוגרפיה וארט־דיירקשן רספונסיבי |
| Alina Wheeler, *Designing Brand Identity* | PDF, 352 עמ'; טקסט ואיורים | מערכת זהות, עקביות מותגית ונקודות מגע |
| Timothy Samara, *Making and Breaking the Grid* | PDF, 212 עמ'; טקסט ואיורים | גריד, קצב, יישור ושבירה מכוונת של מבנה |
| Erika Hall, *Just Enough Research* | PDF, 163 עמ'; טקסט נגיש | ניסוח שאלות מחקר, הפרדת ראיות מהשערות ומחקר רזה |
| Adam Silver, *Form Design Patterns* | PDF, 386 עמ'; טקסט, קוד ואיורים | סדר שדות, תוויות, שגיאות, תלות בין שדות ונגישות |
| Heydon Pickering & Andy Bell, *Every Layout* | PDF, 265 עמ'; טקסט וקוד | פריסות CSS עמידות, intrinsic design ורכיבים ללא breakpoints מיותרים |

## זמינות ופערים

- לא נמצאו בסריקה: *Standout Designs for the Web*, *CSS in Depth, Second Edition*, *Web Accessibility Cookbook* ו-*The Photographer's Eye*.
- מהדורה ושנת פרסום תועדו רק כשהופיעו באופן אמין במטא־דאטה או בדף השער; אין להסיק אותן משם הקובץ.
- מקורות עיצוב חזותיים דורשים בדיקת עמודים ואיורים ממוקדת; חילוץ טקסט לבדו אינו מספיק.
- הספרים אינם מחליפים תקנים עדכניים. בהחלטות נגישות, אבטחה ו-Web יש להעדיף תקן ופלטפורמה נוכחיים.
